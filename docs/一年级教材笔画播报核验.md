2026-11-12 后续范围已扩至所供 12 册涉及的 2,983 字，见 [教材笔画完整性修复](教材笔画播报完整性修复.md)。下文保留一年级阶段的核验范围与统计。


日期：2026-11-10。状态：名称修正与资源补充已实现，自动化及浏览器检查通过；用户已确认四段新录音验证通过。范围仅为已接入的一年级上下册，未部署。

例如“学”第 5／6 笔分别为横钩／横撇，“感”第 7／11 笔分别为斜钩／卧钩，“疑”第 8／10 笔分别为横撇／横钩。“安”本轮已消歧；范围外的“宇”仍保留原歧义，不用它替代未完成的校对。

修正后，一上 280 字、一下 495 字（两册去重 690 字）的名称数量均与本站字形笔数匹配，各笔均有名称与对应录音。该结论是名称／资源完整性检查；本轮只核对新增的 180 个歧义位置，不代表其余字典答案或所有动画轨迹已完成教学审核。

全库仍有 1,946 字存在歧义、2,763 字没有名称、4 字名称数量冲突；它们继续保留原来的未知／错误处理。尚未启动二至六年级的同类集中校对。

## 证据与实现

- 笔顺位置使用仓库原有 [GF 0023—2020](../GF0023-2020《通用规范汉字笔顺规范》.pdf)：定位各字 UCS，渲染 10 张核对图查看每个序列，局部放大复查“疑、柔、野”等位置。不是从五类笔画代码直接推断折笔名称。
- 名称分类参考教育部 [GF 2001—2001](https://www.moe.gov.cn/ewebeditor/uploadfile/2015/01/12/20150112170016626.pdf) PDF 第 9—10 页（印刷页 6—7）的折笔表，已渲染并旋转查看。“卧钩”沿用已有的心类钩常用 UI 名称，不声称该名称就是表中全称。
- [逐字核对记录](../resources/textbooks/grade1-stroke-review.json) 保存来源 SHA-256、两册内容快照 SHA-256、UCS、PDF 页序、原页裁切坐标、原字典候选、零起笔画索引及确认名称。按精确字和索引接入已有 `corrections.js`，不替换原字典或字形文件。
- 单测核对原候选没有漂移、修正只属于教材范围、名称来自原候选、690 字没有未命名或未录音笔画，并保留范围外未知情况。

用本地原件复看任一字（需要 PyMuPDF，不联网，不修改原件）：

```bash
python3 tools/render-grade1-stroke-review.py /private/tmp/bishun-grade1-review --character 学
# 不指定 --character 则输出全部 156 字的原页片段。
```

## 录音与体验

原有 26 段笔画录音的字节、元数据和用户确认保持不变；新增四段共 27,728 字节，使用同一 edge-tts 7.3.1／zh-CN-XiaoxiaoNeural／-10% 制作、相同去静音流程，仅在内容制作时联网。总数增至 30 段。新增项最初为 `pending-listening`，用户于 2026-11-10 回复“验证通过”后，本批四段更新为 `reviewed`；日期及独立确认方式写入清单，仅适用于这四个成品文件，不扩展至“禾／田”或其他录音。

| 新名称 | 体验字与笔画 |
| --- | --- |
| 竖折撇 | 专第 3 笔、转第 7 笔 |
| 横折弯 | 朵第 2 笔、船第 8 笔 |
| 横折折折钩 | 奶第 4 笔、杨第 5 笔 |
| 横撇弯钩 | 阳第 1 笔、部第 9 笔 |

刷新后输入“专朵奶阳”，选择“听讲解”；也可从小学教材进入相关课次。主界面与教材顺序不变。新离线字单按需收集这些录音；已有字单需联网刷新并主动更新离线包，才能获得新名称映射及所需文件。

只制作待试听片段（不修改确认状态，需要 ffmpeg）：

```bash
python3 tools/prepare-audio-review.py /private/tmp/bishun-grade1-new-stroke-review --pending-only
```

本批确认前输出四段，依次为“横折弯、横折折折钩、横撇弯钩、竖折撇”，含间隔约 7.21 秒。四段均确认后，`--pending-only` 当前没有待试听项；不加参数仍生成全量片段。

- 48 字／233 笔既有样本、100 项 Node 回归、30 份笔画录音校验及生产构建通过。所有 156 个原页片段可按记录坐标重新渲染，来源哈希及 UCS 校验通过。

- 自动播放、技术校验与规范核对不代替用户听辨；四段新录音已经用户单独确认，没有继承原 26 段的试听结论。
