## 如何体验

右上角菜单 → **小学教材** → 选择年级册次 → 单元 → 课文或语文园地 → 会写／会认 → 打开本课，也可点字进入对应位置。

继续使用同一个册次选择框，不增加主页面常驻目录。跨册只改变选课草稿，确认后才替换查询；取消保留原字组和位置。不会自动播放或收藏，浏览器刷新只恢复最后确认的选课位置。

## 按原件保留的差异

- 所供六年级原件只有写字表，本轮会认按钮按任务禁用，不补造识字记录；默认打开会写。
- 五下第三单元、六下后续综合内容等没有对应字表任务，不生成空任务或强行补足八个可选单元。五下保留单元编号 1、2、4、5、6、7、8；六下有字任务位于单元 1—5。
- 三至五年级部分附录只印“语文园地”，没有编号。根据其所在的前序课文及已校对目录确定单元，与校正后的工作簿单元交叉校验，再独立命名为“语文园地三”等。原标签保存在 `sourceLabel`，不沿用前一课的 ID，也不把会认／会写的不同前序课号拆成两个园地。
- 二下及更高年级的写字表共 1,950 条原本没有注音，数据保留 `null`；预览只显示字，不显示“null”或编造“教材注音”。识字表注音仍要求有效；进入主画布后继续使用现有字典全部候选，不把字典候选倒填成教材来源。
- 六下古诗词附录的独立编号不覆盖主课文；“鲁滨逊漂流记（节选）”“匆匆”等主课归属沿用既有校对结果。

## 来源与制作

只使用 `refs/` 已有工作簿和 12 册 PDF，没有重新下载、覆盖或提交原件。复用 [原件校对](教材字表校对结果.md) 与 [独立校正层](../resources/textbooks/proofread-corrections.json)，先按原值核验并应用对应册次的校正，再导出会认／会写内容。`source.appliedCells` 统计该册整个工作表应用的校正单元格，包含未开放词语行的元数据，不等于仅字项的修正数量。

来源文件的哈希与校正层哈希随每册保存。一年级两册源数据及公开 JSON 保持原哈希不变。内容源位于 `resources/textbooks/pilot-v1/`，公开 JSON 位于 `public/textbooks/pilot-v1/`，使用内容哈希地址，运行时按册加载并独立缓存。

本次数据对应用户提供的原件版本，没有查询或宣称统一教材最新版。原资料另外 10 个词语表的 2,162 条词语记录仍保留在校对层，本轮不新增词语选择／拆词交互。

```bash
# 正常开发、构建自动执行；只需要 Node 和已提交资源。
npm run textbooks:check

# 仅显式重制时使用：需要本地原件、Python、PyMuPDF、openpyxl。
npm run textbooks:prepare

PYTHONDONTWRITEBYTECODE=1 python3 -m unittest discover -s test -p 'test_textbook_proofread.py'
```

构建检查 12 册数量、任务／字项／园地数、真实单元编号、内容与公开文件一致、字节数／SHA-256／地址版本、原件与校正层哈希；不联网下载，不依赖运行时解析 Excel 或 PDF。
