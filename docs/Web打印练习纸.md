## 使用与数据

右上角菜单中的“打印练习纸”先暂停播放，再进入独立 `/print/index.html`。地址片段保存当前组及当前字索引，预览可选择当前字或整组、米字格／田字格、16／20／24mm 格子、每字 1—3 行；每字首格为范字、接着两格浅色描红，其余为空白格。保留顺序与重复字，返回查字恢复原组但不自动播放。

使用现有 CharacterStore 加载及校验字形，最多两路并发；不加入新的字形来源、拼音或逐笔拆分图。缺字／加载失败逐项提示，打印暂不可用；用户可重试或明确移除问题字，不能将空白范字当作成功。移除仅影响当前预览。许可加载失败同样阻止打印；直接调用浏览器打印时，未就绪页面只打印未就绪提示。页面离开取消任务，参数切换防止旧结果回写，后退缓存恢复重新准备内容。

字形依据锁定包中的 ARPHICPL.TXT 分发：范字和描红复用原笔画路径，输出注明来源、生成日期与排版转换说明，并附完整未改动的许可文本；许可证在纸上以单独附页排版。字体软件许可与规范 PDF 的图形复用是不同来源，本功能没有提取 GF 0023 图形。

## 打印与验证

浏览器原生打印，支持的系统可另存 PDF，不自建 PDF 引擎。A4 纵向，每字练习块不拆页，内容显式分页，末尾附许可页；纸面不显示控件。手机预览可在纸张区域横向滚动，不让整个网页横向溢出。

- `npm test`：48 字／233 笔，47 项 Node 回归通过；包含九种字号／行数组合的分页边界与重复字保留。
- 构建输出四个 HTML 入口；资源与录音前置检查通过；新模块语法及 diff 检查通过。
- Headless Chrome 156.0.8078.80 生产页检查：当前组／当前字入口及返回不自动播放；20 字、24mm、3 行生成 7 张练习纸＋1 张许可页；打印媒体隐藏控件，内容不越过页脚；田字格切换、当前字范围、320px 局部滚动；实际缺字明确移除后可打印；许可阻断及恢复重试。未捕获异常为 0。
- 实际导出 PDF，用 PyMuPDF 核对 8 页 A4 及许可尾文；渲染查看练习页和许可页，字形、描红、分页、许可与页脚无截断重叠。修改许可页行距后重新构建和导出复核。

```bash
node test/browser-print.mjs <CDP地址> <生产首页地址>
```

尚未替代真机系统打印／分享 PDF 面板与实体打印机检查。浏览器页眉页脚、纸张缩放和目标打印机设置需由系统打印界面确认；本功能没有将已有手机核心验收扩展为新增打印流程通过。
