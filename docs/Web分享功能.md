# Web 分享功能（F2）

日期：2026-11-08。已实现并在本地生产构建验证，尚未部署。

“笔画与设置”提供分享入口，弹窗选择当前字或当前组。打开时读取查询快照，保留字序和重复字；未提交的输入不参与分享。链接只带 `#q=` 汉字内容，清除原 URL 的查询参数和片段，不附带姓名、收藏标题、历史或设置。片段不会作为 HTTP 请求路径发送，但接收者和浏览器仍可读取文字，不能视为保密机制。

接收端验证完整的 1—20 字 Unicode 汉字序列；重复参数、非法字符和超限链接拒绝恢复，不静默过滤。有效链接查询后不自动播放、不自动收藏，缺字沿用现有提示。刷新恢复同一查询，hash 导航更新查询；手动提交新查询时移除旧 q 参数，避免刷新返回旧内容。原预览兼容入口仍保留 hash。

可用时调用系统分享；同时提供复制链接，剪贴板不可用或被拒绝时选中链接供手动复制。取消系统分享不报错；失败给复制路径。关闭弹窗恢复入口焦点。没有二维码或后台代发服务；本地地址需接收设备可访问。

验证：48 字／233 笔、46 项 Node 回归及生产构建通过；分享模块和应用语法、diff 空白检查通过。独立 Headless Chrome 156.0.8078.80 完成 5 组检查：单字／整组快照，复制兜底和焦点，链接与刷新恢复不播放／不收藏，手动查询清旧链接及无效链接，系统分享取消分支与 320px 弹窗布局；未捕获异常为 0。

```bash
node test/browser-share.mjs <CDP地址> <生产页面地址>
```
