# Web 分享功能（F2）

日期：2026-11-09。已实现并在本地生产构建验证，尚未部署。

右上角菜单提供分享入口，弹窗选择当前字或当前组。打开时读取查询快照，保留字序和重复字；未提交的输入不参与分享。链接只带 `#q=` 汉字内容，清除原 URL 的查询参数和片段，不附带姓名、收藏标题、历史或设置。片段不会作为 HTTP 请求路径发送，但接收者和浏览器仍可读取文字，不能视为保密机制。

接收端验证完整的 1—20 字 Unicode 汉字序列；重复参数、非法字符和超限链接拒绝恢复，不静默过滤。有效链接查询后不自动播放、不自动收藏，缺字沿用现有提示。刷新恢复同一查询，hash 导航更新查询；手动提交新查询时移除旧 q 参数，避免刷新返回旧内容。原预览兼容入口仍保留 hash。

可用时调用系统分享；同时提供复制链接，剪贴板不可用或被拒绝时选中链接供手动复制。取消系统分享不报错；失败给复制路径。关闭弹窗恢复入口焦点。已补充按需二维码（见下文），没有后台代发服务；本地地址需接收设备可访问。

链接初版验证：48 字／233 笔、46 项 Node 回归及生产构建通过；分享模块和应用语法、diff 空白检查通过。独立 Headless Chrome 156.0.8078.80 完成 5 组检查：单字／整组快照，复制兜底和焦点，链接与刷新恢复不播放／不收藏，手动查询清旧链接及无效链接，系统分享取消分支与 320px 弹窗布局；未捕获异常为 0。

```bash
node test/browser-share.mjs <CDP地址> <生产页面地址>
```

复制不可用和系统取消通过测试会话内替身触发，未进行真实系统转发；iPhone／iPad 的系统分享面板和剪贴板权限仍需新增功能专项实机确认，不能沿用此前核心手机验收结果。


## 二维码补充（2026-11-09）

入口仍为右上角菜单 → 分享 → 二维码，默认不展开。编码与当前分享链接完全相同：只含网站地址和查询汉字，不追加生字本名称、历史或设置；保留重复字和 20 字／Unicode 边界，不引入短链接或服务器二维码服务。首次点开才加载本站生成模块。选择当前字／整组会立即清除旧图片并重新生成；关闭或收起使待处理结果失效，迟到模块不能重新展开或写回旧图片。

显示黑白 PNG、四模块白边和 M 级纠错；提供“保存图片”，下载与所显示二维码相同的 PNG。仅图像数据在浏览器内生成，不持久保存到本地存储。分享范围改为同排的单选项，单字查询隐藏整组选项；320px 下操作按钮可换行，二维码在弹窗内滚动，首页未新增入口。

模块等待最多 3 秒；失败／超时显示“二维码暂不可用，可复制链接”，原有复制／手动复制与系统分享仍可用。超时后的模块若稍后加载成功，下次点开可复用；实际导入失败被浏览器缓存时可能需要恢复网络并刷新。二维码不改变接收端的查询恢复行为，不自动播放或收藏；局域网地址仍要求接收设备可访问，扫码不会使本地站点自动上线。

来源：[qrcode-generator 官方项目](https://github.com/kazuhikoarase/qrcode-generator)，锁定 2.0.4，无运行时子依赖，MIT 原文从官方仓库取得并复制到 `public/licenses/qrcode-generator-LICENSE.txt`，随站点分发。生成模块构建约 22.03 KB（gzip 8.14 KB 为构建报告，非网络实测），不参与初始页面加载。仅测试使用 jsqr 1.4.0（Apache-2.0）作独立解码器，没有纳入网页运行时模块。

自动复现：

```bash
node test/browser-share-qr.mjs <CDP地址> <生产页面地址>
node test/browser-share.mjs <CDP地址> <生产页面地址>
```
