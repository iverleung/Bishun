## 行为

- 初始页保留品牌、大输入框和最近查询，原输入与历史事件继续复用。
- 结果页顶部只显示“搜索图标＋当前查询字组”和右上角菜单，长字组截断显示；可访问名称及 title 保留完整字组。工具栏常规高度 48px，安全区按设备补足，页面滚动时仍可访问。
- 点字组打开顶部搜索弹窗，复用同一个输入框、查询历史与 20 字限制。仅主动打开时聚焦输入；关闭后恢复到工具栏，不把焦点交给隐藏输入。
- 打开搜索先暂停演示或练习。编辑草稿不会改变当前字组；取消、Esc 或遮罩关闭会丢弃草稿，保留当前字、笔画及练习进度，不自动续播或恢复输入。
- 面板中的“清空”只清输入草稿，不立即清除结果。清空输入后提交会回到初始查询页；有效提交或点选历史会收起弹窗，展示新查询，不自动播放。
- 只有非汉字的非空草稿在面板内提示“请输入汉字”，保留旧结果；混合／超限查询仍沿用过滤规则，在结果区保留异常提示。
- 保留输入法组合输入保护；取消时清除中断的组合状态，避免下一次查询无法提交。

## 布局和实现

正常结果页按视口扩大字格，最大 440px；手机预留两侧候选提示及渐隐范围，并按小视口高度给普通播放控件留空间。拼音／笔数仍在字格上方，练习与专注模式沿用各自的尺寸规则，不增加常驻说明或首页功能入口。

搜索表单在初始页容器和原生 dialog 之间移动，不复制输入、历史或事件。复用既有弹窗控制，补充初始焦点与关闭回调配置；滚动锁、滚动条宽度补偿、Tab 焦点约束、Esc 和遮罩关闭沿用同一机制。原菜单的默认行为不变。自动化 fill 辅助函数改为通过真实工具栏打开搜索，再填写现有输入。
