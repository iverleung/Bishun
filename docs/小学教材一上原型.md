# 小学教材：一年级上册原型（P1）

后续进展：现已增加一年级下册与册次选择，当前范围见 [一年级上下册接入记录](小学教材一年级上下册.md)。以下保留 P1 首次交付时的范围与验证。

日期：2026-11-10。范围：已校对的一年级上册，“会写／会认”与独立语文园地。其他册次和词语入口尚未开放。

## 如何体验

右上角菜单 → **小学教材** → 选择单元和课文／语文园地 → 点击“打开本课”，或点击其中一个字进入对应位置。

首次默认第一单元“天地人”：本课没有会写任务，显示会认“天地人你我他”。点击“金木水火土”默认显示会写“一二三上”，可切换会认。教材没有设置某类任务时按钮禁用，不编造空任务。

入口打开独立面板，桌面分为目录与字单预览，手机为全高面板、单元选择和横向课次列表。只有一册可用时直接显示册名，不展示尚未开放的年级／册次选项。选课完成后收起面板，主页面仍以原大字格为中心，不增加课程横幅。

## 数据与来源

- 38 项任务：30 项有字任务的课次、8 个独立语文园地；284 条会认出现记录（含 4 条蓝字多音记录）、100 条会写出现记录全部保留，不合并同字或不同读音条目。
- 每条字项保留教材注音、蓝字标记、原工作簿行号和 PDF 物理页。预览显示教材原注音；载入主画布后沿用现有字典全部候选，不按课名自动选读，不改全局字典。
- 园地按原页标签生成 `garden-1` 至 `garden-8`，不沿用前一课课号作身份。低年级识字、汉语拼音、阅读分别编号；课题修订不会改变任务 ID。
- 应用了一上 141 个单元格校正：100 个会写字注音、“绿”的字体编码、20 个右栏字的课序及其课题。原件及原工作簿保持不变。
- 一上识字表部分区域是局部双栏。P1 建模补查发现，前轮解析漏了右侧带字课号，导致 4、8、9、13、14 课的 20 个字被并入左栏。已独立提交修正 `4ba9783`，新增实际原件回归；当前课程数据使用补查后的校正层。完整说明见 [校对结果](教材字表校对结果.md)。

内容源位于 `resources/textbooks/pilot-v1/`；前端只在用户打开教材面板时请求 `public/textbooks/pilot-v1/` 中带内容哈希的 JSON。不会在运行时解析 Excel、读取原 PDF、登录教材平台或访问外部数据 CDN。

本册是所提供原件的内置试用数据，不标成当前全部教材的统一最新版；原件哈希及校正清单哈希随内容源保存。内容标注与授权核验仍遵循 [整合方案](教材字表整合方案.md)，本轮没有部署。

## 查询、练习与收藏

- 选择单元、课次和分类仅改变面板草稿。取消／Esc 后原查询、当前字和已完成笔画不变；焦点返回可见的菜单按钮，不落到已关闭抽屉里的入口。
- 打开面板暂停演示和屏幕练习、取消拼音录音。关闭不自动继续。确认课次才替换字组、作废旧动画／音频／练习及选字回调。
- 点字也载入完整课内字组，然后选中对应位置，不把其他字丢掉。已有 20 字限制不放宽；无效／超长教材数据会拒绝，不静默截断。
- 载入后不自动播放。描红／背临、整组演示、分享和现有打印入口继续复用；本轮不增加打印拼音开关或课名排版，这些属于后续配套增强。
- 内置教材与“我的生字本”独立。仅打开教材不新增收藏、不占 30 条额度；需要时使用原有收藏当前字／这组字入口，保存为个人副本，后续可自行命名和编辑。
- 本地只保存最后确认的教材浏览位置（册、单元、任务、分类），方便再次打开；刷新仍回到原有输入首页，不自动恢复课次查询或开始播放。存储不可用时本次使用仍正常。
- 菜单入口下方可以看到本次选课位置，自由查询／打开普通字单后清除当前课程标记，避免给其他查询贴上旧课题。

## 离线和失败状态

首版只承诺现有已保存字单的离线查字、播放、练习，不承诺离线选课或整册资源已下载。教材 JSON 不自动加入所有离线包；联网打开后可在本次页面内复用已加载目录。离线字单仍按用户主动保存的字组去重下载必要字形与录音。

教材加载失败有独立重试入口，不改变当前查询；响应类型错误、损坏 JSON、超长字组、重复记录 ID 和残留拼音编码会拒绝。请求与读取有 5 秒预算，关闭面板取消等待；即使旧请求忽略取消且晚到，也不能重新打开面板、替换新查询或定位到旧字。

```bash

npm run textbooks:check

# 只有明确重新制作本册数据时使用，需要本地原件、Python 3、PyMuPDF、openpyxl。
# 校验来源哈希，应用校正，不改 refs/；不是正常构建前置下载。
npm run textbooks:prepare
```

构建校验公开 JSON 与内容源完全一致、文件字节数／SHA-256／地址版本一致、校正层哈希一致，并检查 38 项任务与 384 条原始出现记录。暂未做转换工具的通用全版本支持，新增册次需先校对再转换。
