- `reading`：NFC 归一化的带调拼音；轻声不加调号。不同声调分别存放，保留 ü、ê 和成音节鼻音等特殊拼写。

## 给音频生成 Agent 的约定

每个 `reading` 生成一份独立录音，多个同音同调汉字共享。不直接把多个例字连读成一个音频，也不将拉丁拼音串或第一个例字未经核验地当作可靠发音输入。例字用于选取发音文本及校对，多音字、轻声和罕见音节需要明确发音策略并试听。

无法可靠合成的条目保留为失败／待人工处理，记录音节及原因，不用其他声调或近似读音代替，也不将失败条目从完整列表中删除。罕见字和扩展区字还可能超出本站字形范围；这里仅提供音节和例字，不承诺其字形能在产品里演示。

按音节与文件 SHA-256 记录生成参数、审核状态及产物映射。更新清单不会自动替换站点现有录音；音频是否正确仍需试听，字典集合一致性检查不等于发音审核通过。
