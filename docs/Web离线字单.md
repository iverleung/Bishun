## 使用

在构建后的 HTTPS 网站或电脑 localhost 中查字，进入右上角菜单 → 离线字单 → 保存这组字。可以先从“我的生字本”打开某组，再保存离线副本。保留 1—20 个汉字的原顺序和重复字，字形与录音按实际资源去重。

保存完整后才显示“离线可用”；点字单可打开，仍需主动播放或进入练习。断网刷新后可以从菜单离线列表、原有历史或输入相应汉字继续使用。未保存的字明确显示“此字未离线保存，请联网后查询”，不会拿空白字形冒充成功。

提供更新、删除与下载中取消。离线副本与生字本独立：删除离线资源不删除收藏、名称或历史；生字本编辑不自动覆盖原离线副本。最多 10 组、已提交资源逻辑上限 20 MiB；UI 显示约数，不等于浏览器磁盘总占用。更新暂存新旧两份，因此浏览器实际配额不足时仍可能失败，不静默淘汰其他字单。

只下载当前所需字形和有名称的笔画录音；字典名称暂缺时保留未知，离线列表注明“部分笔画名称暂缺”，不生成默认名称或承诺全字库教学审核。缺字、笔数／名称冲突、缺录音、损坏资源或超时会使整组保存失败，不发布半份字单。

## 环境与体验入口

Service Worker 受安全上下文限制，正式设备需 HTTPS；浏览器将 localhost 视为开发用安全来源。当前 `http://192.168.6.169:5188/` 只能在线使用，菜单中明确提示 HTTPS 要求并禁用保存；不会用不安全浏览器标志绕过限制。

本次另启动电脑本机体验服务 `http://localhost:5189/`，保留原局域网服务不变。其他开发环境可按标准命令构建和预览：

```bash
npm run build
npm run preview
# 或给已构建产物提供本机服务
python3 -m http.server 5189 --bind 127.0.0.1 --directory dist
```

`npm run dev` 不生成可离线的完整构建，菜单会给出构建提示。离线数据与当前协议／域名／端口绑定，localhost、局域网 HTTP 和未来 HTTPS 网站的离线包不互通。无需安装到主屏幕。

浏览器存储属于尽力保留：清理网站数据、隐私模式或浏览器回收都可能移除资源。列表会检查资源是否齐全，缺项显示“资源不完整”，允许联网更新或删除；没有完整离线包时，断网冷启动返回清楚的联网提示，不宣称永久可用。

依据：[MDN Service Worker 安全上下文](https://developer.mozilla.org/en-US/docs/Web/API/Service_Worker_API/Using_Service_Workers)、[浏览器存储配额与回收](https://developer.mozilla.org/en-US/docs/Web/API/Storage_API/Storage_quotas_and_eviction_criteria)。

## 资源与更新

构建自动生成 `offline-build.json` 和独立打包的 `offline-sw.js`。清单记录构建标识及必要 HTML／JS／CSS、现有图标、字形清单、录音清单和许可的 SHA-256；不枚举下载全量字形。字形用原 `checksums.json` 与资源集哈希核对，再复用 CharacterStore 路径、笔数和名称校验；录音核对清单、文件哈希与大小。文本／模块类型也要有效，HTML 回退不能冒充字形或脚本。传输压缩按解压后的实际字节校验并保存，不保留压缩传输头。

每组使用独立的 Cache Storage 快照，包含离线重开页面所需的完整代码和许可。应用壳／许可有重复存储，选择它来简化删除和更新的完整性。没有后台全库预取、账号同步或二维码上传字单名；下载请求仅指向本站资源，字单名称等元数据只写浏览器。

下载到临时缓存并完成全部校验后，最后写入元数据作为提交点；提交前失败或取消删除暂存，旧副本继续可用。完成后尽力回收旧快照；中断留下的无元数据暂存下次保存时回收，旧完整副本在列表去重，删除时一并清理。写操作由 worker 串行处理，提交边界再次检查取消；10 组限制按逻辑字单计数。

单项请求及响应体读取有 5 秒预算和大小限制，保存 RPC 最长 120 秒，管理操作 15 秒；支持显式取消。存储不足、资源异常与版本变化均不记为成功。更新 worker 不刷新页面、不清离线副本；旧页面若与保存服务版本不同，要求联网后手动刷新再更新。

已保存的不可变资源优先从缓存读取，断网或连接停滞时不等网络超时；页面导航先联网，2 秒预算后回退到最新完整快照，保证能获取新版页面。更新包直接请求并校验网络资源，不拿旧缓存冒充更新。Cache Storage 读取失败时仍尝试正常网络，不让离线功能破坏在线访问。

## 验证

- 48 字／233 笔样本、77 项 Node 回归、四入口与 worker 构建、相关语法及 diff 检查通过；未新增 npm 依赖。离线单测覆盖资源去重、精确哈希、未知字、取消（含元数据提交阶段）、配额模拟、数量／字节限制、读取体超时、资源类型、文件缺项、版本不匹配，以及异常残留副本的计数与删除。
- 隔离 Headless Chrome 157.0.8103.39，5 组离线端到端检查通过：保存“木水木”实际只含 2 个字形／6 份录音；测试 HTTP 服务关闭所有连接后刷新，重新打开、播放录音／动画并完成手写；未下载“心”明确提示；失败／取消更新保留旧包；成功更新替换旧包；不同构建标识的新 worker／新壳更新不刷新当前页面，随后断网刷新取得新壳；删除不动生字本，无包冷启动有明确提示。服务器统一 no-store、页面 HTTP 缓存关闭，缓存字形／音频在断网读取时未请求服务器；不是仅验证同页内存缓存。
- 2 组能力检查通过：普通 LAN HTTP 明确拒绝离线保存，已有 localhost 体验服务可以启用主动保存，未点击保存不下载字单。
- 相关回归：查询工具栏 7、连续练习 9、既有练习 8、抽屉／切字 8、动画坐标 3 组通过。三个动画视口坐标差均为 0，保留缺失 viewBox 的负例；无未处理页面异常。已查看离线已保存、HTTP 提示与本机准备状态的移动抽屉截图。
