# Web 播放重构（W3）

日期：2026-11-08。状态：已接入真实字库、轨迹动画与预生成录音，完成开发环境验证。保留已确认的 UI；未替换旧首页，未发布。

## 访问与结构

`npm run dev` 后访问 `/preview/index.html`；`npm run build` 后该入口仍在 `dist/preview/index.html`。Vite 同时构建旧首页与新版，运行时互不混用播放状态。

- `preview/index.html`、`src/web/`：已确认的布局、交互、历史与视图过渡；移除六字模拟数据及演示故障开关。
- `src/data/character-store.js`：复用 W2 的同源资源、校验、缓存、去重和超时。当前字优先，后续字两个并发预取；不回落到外部 CDN。
- `src/playback/controller.js`：唯一播放任务、查询快照、笔画位置、节奏、整组跳字与取消规则。
- `src/playback/hanzi-animation.js`：HanziWriter 真实轨迹适配；完成笔静态显示，当前笔使用独立动画层。
- `src/playback/stroke-audio.js`：Web Audio 解码、缓存与播放本站 MP3，直接由用户动作解锁声音；不调用语音合成。

## 行为与取消

查询支持最多 20 个 Unicode Han 字符，保留重复字及词序；输入框继续编辑不改变现有结果。先显示完整字形，再主动播放。缺字、结构异常及名称数量冲突显示明确失败，可重试或切到其他字。名称未知显示“暂缺”，不补播“点”。

每笔先准备对应录音，再同时启动轨迹和声音；两者结束才进入下一笔。录音保持正常语速，动画速度在下一笔生效。快速看默认静音、听讲解启用录音、跟着写每笔暂停；整组模式跟写到字边界也等待继续。定位是静态且静音的，重播本笔只播放目标笔。

暂停保留完成笔，中断笔继续时从该笔起点重播。切字、新查询、清空和后台暂停均取消旧任务，旧加载结果与回调不能推进新会话。整组切字加载中也能暂停，回来需手动继续。整组跳过失败字，结束保留最后一个成功字并提示跳过数量；全组失败保持错误。

动画仅使用当前依赖的公开 API：`getCharacterData`、`animateStroke`、`pauseAnimation`，速度使用 `strokeAnimationSpeed`。不使用不存在的 `cancelAnimation` 或未支持的单笔 duration 参数。取消时立即移除该笔所属动画层，旧清理不能移除新层。动画等待上限 10 秒；录音清单／文件与解码等待上限各 3 秒，播放等待按解码时长加 1.5 秒封顶。录音失败提示并静音继续，关声音立即取消准备或播放。

## 已验证

- `npm test`：48 字／233 笔名称样本通过，32 项 Node 回归通过。新增覆盖暂停后仅重播中断笔、过期完成、切字与清空、整组加载时暂停、跟写边界、失败跳过、音画共同结束、关闭语音取消准备、下一笔变速等。
- 音频适配器回归覆盖同源地址、解码缓存、替换与取消、晚到准备结果、坏清单／解码／声音上下文失败；资源测试补充浏览器默认 fetch 接收者检查，修复实际浏览器中的 Illegal invocation。
- `npm run build` 通过，输出双入口及本地资源；26 份录音文件／清单技术校验通过。构建曾在清理旧 `dist/characters` 时遇到间歇性 `ENOTEMPTY`，顺序重跑通过，尚未确定该本机文件系统问题的原因。
- 内置浏览器：查询“春风又绿江南岸”，真实字形与队列正常；轨迹播放期间存在独立 HanziWriter SVG，完成后动画层清空。
- “木”听讲解播放完成 4 笔，实际录音路径完成；暂停续播、定位到第 2 笔再重播本笔、播放中切“水”没有旧任务继续推进。
- 20 字整组（含重复“一”和缺字“𠮷”）完成到 20/20，提示跳过 1 字；缺字后手动切“水”能恢复；编辑输入框为新词不改变现有播放快照。
- 跟写每笔暂停，320×820 视口画布中心 x=160；页面宽度与 scrollWidth 均为 320。桌面实际内容宽 1265，画布中心 x=632.5，无横向溢出。最终检查控制台未见 error／warn。
