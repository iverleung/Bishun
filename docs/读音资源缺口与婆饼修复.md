[机器报告](读音资源覆盖检查-2026-11-11.json) 保留每册字数、完整／部分／无录音字符、原注音记录覆盖、全部缺失音节及对应字。报告绑定各册 JSON 和录音清单 SHA-256，可复算；不是全 9,574 字库的覆盖结论。

```bash
npm run --silent audio:readings:coverage
node tools/check-reading-coverage.mjs > docs/读音资源覆盖检查-2026-11-11.json
```

原 `audio:readings:check` 负责现有文件的来源与完整性，不意味着全教材覆盖。本次将两类检查明确分开，避免用“资源校验通过”代表“每个字都能点读”。
