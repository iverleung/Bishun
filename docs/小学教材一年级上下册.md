## 体验

右上角菜单 → **小学教材** → 选择“一年级上册／一年级下册” → 单元 → 课文或语文园地 → 会写／会认 → 打开本课。也可点其中一个字，将整组带入画布并定位该字。

一下默认从第一单元“春夏秋冬”开始，会写为“春冬吹花飞入”；每册的 8 个语文园地均是独立任务。主页面继续复用既有查字、演示和描红／背临，不增加常驻课程区，不自动播放或收藏。

## 册次切换与加载

- 首次默认一上；再次打开回到最后确认的册次、单元、任务和分类。刷新不恢复课文查询或自动播放。
- 切换册次是面板草稿，只有“打开本课”或点字确认才保存。取消不修改原查询或已确认位置。
- 各册独立按需加载及缓存；切回已加载册次复用本次页面缓存。不预先加载其他册次，不在运行时解析原件。
- 同名任务 ID 按册隔离。切到另一册不会误用前一册的单元、任务或会认／会写选择。
- 请求失败可在当前册重试。切册或关闭取消旧请求，即使旧响应忽略取消而晚到，也不能替换当前目录、字组或位置。

保留既有 20 字查询上限、语音／练习暂停、可见菜单焦点返回和显式收藏规则。尚未加入二至六年级、词语、教材打印增强或离线选课；已保存个人字单仍沿用原离线能力。本次没有部署。
