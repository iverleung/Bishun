# Web 生字本管理（F1）

日期：2026-11-08。按功能计划实施，尚未部署。

## 行为

输入框下的“我的字单”改为“我的生字本”，默认折叠；空列表也能进入导入。常态列表只显示清单，点击“管理”才出现编辑、排序、删除，保持查询与画布为主要入口。

已有“收藏当前字／这组字”继续创建清单。在生字本内可增加可选名称、修改汉字、上移／下移；名称最多 40 个 Unicode 字符，清单最多 20 个汉字，保留重复字，容量仍为 30 条。相同文字不能创建第二份清单，编辑冲突提示修改已有项。取消和 Escape 不保存；关闭对话框返回可用控件。编辑清单不修改正在播放的查询快照。

旧 `bishun-saved-queries-v1` 数组在缺少 v2 数据时读取；打开不写入，首次修改将有效条目和名称写入 `bishun-saved-queries-v2`，保留原 v1。后续以 v2 为准，不能把旧页面写回 v1 当作新版同步。存储不可用时维持会话内操作，并提示无法持久保存。

JSON 备份仅含类型、格式版本、清单文字和名称，无历史及偏好。导入限制 100,000 字节、500 个条目，校验字段、长度及汉字，重复、无效和超过 30 条容量的部分分别计数。对话框预览实际待导入内容，确认后追加；取消不改变数据，已有内容不覆盖。导出遵循当前排序。没有账号或自动跨设备同步。
