日期：2026-11-08。拼音候选及笔画数已实现，部首和整字发音明确延期，未部署。

按用户最新反馈，拼音与笔数移到大字格上方居中显示；多音读音并列且窄屏换行，无需展开设置。普通查看时字格下方不重复显示总笔数，逐笔播放仍在下方显示进度。切字／查询加载时不保留旧字的读音或笔数。读音取现有 cnchar 3.2.6 的 `spell(character, 'poly', 'tone', 'low', 'array')`，多音候选分开展示，不推断词语语境，也不标记某个读音为“正确答案”。未知读音、返回原字或不完整代理对均显示“暂缺”。总笔数仅使用有效 CharacterStore 字形的笔画数量，不读取另一个字典计数。
