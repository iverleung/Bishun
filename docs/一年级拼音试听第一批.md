录音文件按音节复用；“妈 mā／马 mǎ”等不同声调使用独立文件。多音候选仍由原字典全部显示，本轮只添加上述音节：例如“校”显示 xiào／jiào，本批仅新增 xiào；“雨”显示 yù／yǔ，本批仅新增 yǔ。没有音频的候选继续保留文字，不擅选上下文读音，不拿其他声调代替。

集中试听约 56.39 秒，按计划清单顺序播放，每段留 0.75 秒间隔：

1. nǐ、wǒ、tā、zhàn、zuò、bà、mā、mǎ、běn、xué
2. xiào、lǎo、shī、tóng、péng、yǒu、ài、jiā、gē、zì

重点听声母、韵母、声调、是否截断或有杂音。来源标记与解码成功不等同于发音已经人工确认，本批 30 段全部为 `pending-listening`。

## 离线与维护

保存／更新个人离线字单时，按候选读音只收集已有录音并去重；重复字保留查询位置，新录音不自动加入所有旧包。旧包需联网刷新版本并主动更新，才能包含本批资源。

```bash
# 显式准备这批资源；需要网络、Python、curl、ffprobe／ffmpeg。
python3 tools/prepare-reading-audio.py --batch grade1-1

# 仅拼接本批待试听录音，不重新合成，不改变确认状态。
python3 tools/prepare-audio-review.py /private/tmp/bishun-grade1-readings1-review --kind readings --batch grade1-1 --pending-only

# 日常构建仅校验本地资源，不下载录音。
npm run audio:readings:check
```

试听工具默认仍处理笔画；`--kind readings` 才处理拼音，`--batch` 限定批次。输出 WAV、包含文件哈希的时间轴 JSON 和试听顺序 Markdown。
