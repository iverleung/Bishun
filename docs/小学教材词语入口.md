# 小学教材词语入口

2026-11-11。在十二册会认／会写基础上接入现有原资料的全部词语表；后续拼音补音继续暂停，未部署。

## 使用

右上角菜单 → 小学教材 → 册次 → 单元 → 课文 → **词语** → 点击词卡。

每张词卡打开一个完整词，画布从首字开始，沿用现有逐字示范和练习；不自动播放或收藏。词语模式隐藏“打开本课”，避免将超过 20 字的一课词语拼接或静默截断。会认／会写仍可打开整组并定位所点字。确认后保存册次、单元、课次、词语模式；刷新只恢复选课位置，不自动查询。取消浏览不改变已有查询。
