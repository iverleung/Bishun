## 来源与许可

- 原始项目：[hugolpz/audio-cmn](https://github.com/hugolpz/audio-cmn)，固定版本 `f759a0f18f27690742957619e1248ed91e9b3f2c`，文件位于 `64k/syllabs/cmn-<音节数字声调>.mp3`。
- 发音人：Chen Wang 王琛；署名作者：Wang Chen 王琛、Hugo Lopez、Nicolas Vion。Copyright 2013 Wang Chen, Lopez Hugo, Vion Nicolas。
- 每份原始 MP3 的 SWAC 标签标明 `SWAC_LANG=cmn`、对应 `SWAC_TEXT`、发音人及 `SWAC_COLL_LICENSE=CC-BY-SA-3.0`；准备脚本逐文件核对，并通过 ffmpeg 解码检查。
- 录音按 [CC BY-SA 3.0 Unported](https://creativecommons.org/licenses/by-sa/3.0/) 提供；保留署名、来源与许可，改编录音应按相同许可共享。原 MP3 字节和内嵌元数据不修改，仅重命名本地文件。此许可单独用于这些录音，不更改其他代码／资源的许可，也不表示作者为本产品背书。
- 站内 `/audio/readings/v1/SOURCE.html` 提供署名和逐文件来源，右上角菜单有入口；`manifest.json` 记录原地址、固定版本、音节、时长、字节数、SHA-256 和试听状态。构建仅校验本地资源，不联网下载录音。

多音字样本没有采用 Edge TTS；单字“田”的修复例外见上节。原因是客户端不支持任意自定义 SSML／音素控制，难以可靠地逐项指定声调和读法。音源的开放许可、文件技术校验和人工听辨是三件事，不能互相替代。

## 离线与维护

保存离线字单时，按所选字的候选读音收集已有音节录音，去重后与字形、笔画名称录音一起校验并保存；未覆盖音节不会使无关字单保存失败。来源说明和录音清单一起进入离线包。旧包联网更新后才包含新增读音，不静默补下载全库。

```bash
# 日常构建自动执行，仅校验本地资源；无需 Python / ffmpeg。
npm run audio:readings:check

# 只有显式重新准备这批样本时运行；需要网络、Python 3、curl、ffprobe / ffmpeg。
python3 tools/prepare-reading-audio.py --batch basics
# 单独重制“田”；需要锁定的 tools/audio-requirements.txt。已存在且来源／哈希一致时复用。
python3 tools/prepare-reading-audio.py --reading tián
# 不加筛选参数会核验并准备计划中的所有批次。
```

重新准备优先复用来源与哈希相同的本地文件，并重新校验标签及解码；仅相同音节、来源和文件哈希可保留原试听确认，变化后的文件重置为 `pending-listening`。正常构建不下载录音，不要求 Python／ffmpeg。扩大范围需先更新批次计划、重新核验来源与许可，新录音不会自动通过人工试听。
