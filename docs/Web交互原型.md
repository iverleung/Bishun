# Web 交互原型交付（W1）

日期：2026-11-08。状态：独立原型已实现，完成开发环境验证；尚未替换正式站，也未完成用户与真机验收。

## 访问

```bash
npm ci
npm run dev
```

在终端显示的本地服务地址后加 `/preview/index.html`。默认端口时为 `http://localhost:5173/preview/index.html`。必须使用显式文件路径：Vite 对 `/preview/` 会回退到旧首页。无需单独构建或安装原型依赖；生产构建会复制原型到 `dist/preview/`。

源文件位于 `public/preview/`，与旧首页的 `src/main.js`、浏览器语音和播放状态隔离。预览顶部可以返回现有工具；这次没有修改旧页面或已有本站优先加载改动。

## 已实现的交互

- 桌面三栏：查字与字单、固定大画布、逐笔列表与设置。平板双栏；手机为紧凑查询、横滑字单、单字画布与控制栏。
- 查询与播放分开，默认展示完整字形；允许输入 20 字、重复字与混合内容，过滤／超限时解释结果并保留原始输入。
- 字导航、上一字／下一字，失败字可单独查看并切换到可用字。
- 笔顺条点选、上一笔／下一笔静态定位、重播本笔、从当前位置继续，以及单字重播。
- 快速看、听讲解、跟着写三种模拟节奏。跟写每笔暂停，整组模式到字边界也等用户继续。
- 单字与整组模式；整组跳过无示例数据字，完成时显示跳过数量。
- 画布格线与轮廓开关、五档模拟速度；切速在下一笔生效。进入后台时暂停，不自动恢复。
- 空白、加载、单字失败／重试、混合成功字单、声音不可用状态可通过“预览状态”和示例按钮检查。
- 中文输入法组合输入保护、语义化表单、键盘按钮、焦点样式、可访问名称和状态，以及减少动态效果样式。

## 原型边界

只含六个示例字：木、水、心、我、山、田。路径复制自仓库已跟踪 fixture；名称按现有测试样例固定，不代表已经完成规范内容审核。

播放用独立定时状态模型模拟，每笔通过透明度变化呈现，**不是正式的轨迹动画**。尚未接入 edge-tts 录音、浏览器真实音频、全量字库、生产资源服务、历史／收藏、全屏或真实加载超时。声音开关仅演示无音频时的提示。

独立模型用于明确暂停／定位／切字语义，并测试过期任务不能回写；W3 仍须把生产动画与音频适配器接到实际播放控制器，不能简单把这套定时器当成已完成的生产调度。

## 验证结果

### 自动检查

- `npm run test:preview`：11 项通过，覆盖重复字顺序、过滤与超限、暂停重放中断笔、过期回调、切字、清空、逐笔重播、跟写停顿、字边界继续、整组跳过不可用字及切模式取消。
- 三个原型 JS 文件的 `node --check` 通过。
- Vite 生产构建通过，并检查 `dist/preview/` 五个静态文件完整复制。
- 正式 `npm test` 仍存在 W0 记录的 10 字名称差异，返回 1；原型测试通过不表示内容回归已通过。

### 内置浏览器检查

- 桌面 1440×1000、平板 768×1024、窄屏 320×820：确认无页面水平溢出。实际 clientWidth 会因滚动条略小于设置宽度。
- 查“木，木 abc水”：保留原输入，说明过滤，结果依次为木、木、水。
- 点第 3 笔：画布显示前三笔，名称为“撇”，可继续或重播本笔。
- 演示中切换到水：恢复水的完整字形，旧字不继续推进。
- 跟写模式：第 1 笔结束后停下，按钮变为“继续”；点下一笔只静态定位。
- “木未水”中切未：显示不可用、禁用播放；再切水可正常查看。
- 320px 发现播放控制按钮换行后修复；复测三个按钮高度均为 48px。
- 最后检查控制台未见 error／warn。截图留作本次交付预览，不等同于用户可用性结论。

本轮顺带观察到旧首页在 320px 视口下存在水平溢出（clientWidth 305px、scrollWidth 396px）。这是开发内置浏览器中的布局观察，不能代表全部设备。
