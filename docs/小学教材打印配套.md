# 小学教材打印配套

2026-11-11。用户已确认词语入口体验通过，继续实施教材配套打印。未部署，不继续扩充录音。

## 体验

右上角菜单 → 小学教材 → 打开会写／会认或一个词 → 菜单 → 打印练习纸。

练习页标题带册次、课题和当前分类；词语还带所选词。普通查询不带教材标题，仍显示“生字练习”。只在当前教材选择与实际查询完全一致时传递标题；不更改原分享链接，不保存教材全文或另行加载整册。返回查字仍按既有分享语义恢复汉字组，不恢复课程身份或自动播放。

打印设置增加一个 **显示拼音** 复选框，默认关闭：

- 开启：每字上方显示全部可用字典候选，多音并列；缺失显示“暂缺”。
- 关闭：完全隐藏拼音行，不设逐字选择。
- 使用与主画布相同的本地 cnchar 3.2.6 候选；不按词语上下文猜读，不称为教材原注音。附页标明拼音来源和这一边界。

当前字／整组、格线、字号、每字行数、重复字及字形缺失处理沿用原功能。词语仍逐字排版，不做整词拼音或整词书写格。选当前字时保留课题，打印范围由现有范围控件确定。

## 分页与参数

沿用 A4 纵向及完整许可附页。先在同宽隐藏测量页中排版当前标题、拼音和字格，读取实际高度后分页；长课题及拼音换行都占用真实高度，整字练习块不拆页，结束即移除测量节点。字号／行数／拼音开关变化重排，不多加载字形或发音。

地址片段 `q`／`c` 保持原语义，可选 `t` 仅作纸面标签。标签最多 100 个 UTF-16 代码单元，拒绝重复标签、控制字符及尖括号，使用纯文本写入；无效标签回退普通标题，不影响字组。标签不是课程认证，也不参与字典候选计算。
