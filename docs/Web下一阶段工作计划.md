## 第一批：查字与纸上练习工具（建议范围）

### F1. 字单管理（已实现）

场景：家长整理每日作业字，老师提前准备演示清单。

- 在已有收藏上增加可选名称、编辑文字和手动排序；默认保持最近保存优先，排序控件仅在管理状态出现。
- 当前查询可存为新字单，或明确选择更新已有字单；不静默覆盖，取消编辑不改原数据。
- 保留最多 20 字／单、30 个收藏项，以及词序和重复字；暂不增加文件夹、标签或多孩子档案。
- 支持本地 JSON 导出／导入，用于备份与手动跨设备迁移。只包含字单，不包含历史与偏好；导入前预览新增、重复、无效和超额项，不静默淘汰旧内容。

实施记录见 [生字本管理](Web生字本管理.md)。

完成标准：旧收藏迁移不丢失；编辑／排序刷新后保留；重复及容量冲突有明确处理；导入检查格式、版本、字符／名称长度和文件大小；存储失败不显示为保存成功；删除字单不打断当前播放。

### F2. 分享当前字／字单（链接与二维码已实现）

实施记录：[分享功能](Web分享功能.md)。

场景：把“今天这几个字”的演示发给家人或学生。

- 支持分享当前字或当前组；链接恢复查询，不自动播放、不自动收藏、不覆盖本地字单。
- 支持的环境使用系统分享，同时提供复制链接兜底；复制不可用时允许手动复制，取消系统分享不报错。
- 首版链接仅包含汉字内容，不包含姓名、字单标题、历史、练习记录或个人设置；操作时明确链接携带这组字。
- 保留词序、重复字和 20 字限制；损坏或超限参数提示处理，不静默截断；缺字沿用现有提示。
- 二维码已作为后续小增强实现：在分享窗口按需本地生成，当前字／整组切换同步更新，可保存 PNG；未增加首页入口或二维码云服务。模块失败／超时可继续复制原链接。

完成标准：另一浏览器打开恢复同一组字；中文编码、重复字及无效参数有回归；刷新／返回不触发自动播放；手机分享与无系统分享能力的环境均有可用路径。开发链接需接收设备可访问，不依赖先发布公网。

### F3. 打印练习纸（已实现）

实施记录：[打印练习纸](Web打印练习纸.md)。

场景：家长或老师将当前字单生成纸上练习材料。

- 从当前字或当前组进入独立打印预览，保留原查询；首版支持 A4 纵向。
- 每字提供范字、浅色描红和空白练习格；可选米字格／田字格，提供少量字号与行数选项，不做复杂排版编辑器。
- 首版不加入逐笔分解图、拼音、释义、姓名班级或教材信息。
- 使用浏览器打印；支持的系统打印界面可另存 PDF，不承诺每台设备入口一致。
- 缺字或加载失败在预览标明，由用户明确移除问题字或返回重试；不能空白冒充成功。生成材料前核实所用字形的许可、署名和分发要求。

完成标准：打印无导航和操作控件；字格不跨页截断，长字单正确分页，黑白可辨；桌面打印预览与移动端打印入口可用；取消后可回原查询；导出 PDF 人工检查版面。

### F4. 单字基础信息（拼音／笔数已实现，部首暂时隐藏）

场景：看笔顺时顺带确认读音、笔数和部首。

实施边界：现有 cnchar 3.2.6 提供本地字典读音，保留多音候选；笔数复用有效字形。部首暂时隐藏，停止页面调用 cnchar-radical；待归部数据来源核验后恢复，不单独硬编码“和”的结果。拼音试听现有 47 段开放许可真人音节录音，首批 13 段与第二批 34 段均由用户分批确认通过，见 [发音样本](Web拼音发音样本.md)。记录见 [基础信息](Web单字基础信息.md)。

- 拼音与笔画数直接居中显示在大字格上方，多音读音并列且支持换行；部首待来源核验后再恢复；总笔数复用当前有效字形，不另取可能冲突的计数。
- 先核验现有依赖的数据能力与许可，再决定是否补充来源；记录未知状态，不把库有 API 等同教学内容已审核。
- 多音字展示多个读音，不凭整组文字擅自选择语境读音；首版不做自动词语注音。
- 拼音发音现有 47 段可追溯来源／许可的真人音节录音，直接点击拼音；首批 13 段与新增 34 段均已分批试听通过，后续扩充仍按批核验，不做语境选读，也不重新引入浏览器语音合成。
- 释义、组词和造句暂不加入；基础信息加载不阻塞查字与播放。

完成标准：信息对应当前字，晚到数据不覆盖新查询；多音／缺信息明确呈现；笔数冲突继续校验，不强行拼接；信息不遮挡画布，多音字在窄屏不溢出。来源不满足要求时先保留笔数，其他字段明确延期。

## 第二批：练习能力，单独确认范围

### F5. 屏幕跟写与自主练习（已补连续流程）

用户要求继续下一项后开始实施，记录见 [屏幕练习原型](Web屏幕练习原型.md)。当前已有描红、背临、主动提示、重来与返回示范，以及从当前字到查询末尾的连续练习、缺字重试／跳过和本次完成反馈；不把浏览器注入触控事件当作真机手感或教学有效性验收。

为当前可正常演示的字提供显式练习入口，沿用大画布；支持描红、无轮廓尝试、提示、重来和返回示范。切模式先停止原动画和声音。

先做小原型验证触控／鼠标／手写笔输入、笔顺与轨迹容错，以及练习画布和页面滚动的关系。提示下一笔，不给书法分数，不把一次描红完成称为“掌握”。首版只显示本次进度，不增加排行榜、打卡、云端轨迹或复习算法；离开不自动保存手写轨迹。

完成标准：切字／取消／后台恢复无旧回调；失败可重试，提示可主动调用；缺资源不能进入；退出后可正常示范；输入不导致意外页面拖动，也不全局禁用页面滚动。实际设备确认触控体验和误判情况后再扩大范围。

### F6. 按字单有限离线（已实现）

用户于 2026-11-09 明确无需开发主屏幕安装，仅实施离线字单。右上角菜单按需保存当前组及必要运行代码、字形和录音，最多 10 组、资源约 20 MB；完整校验后才标为可用，支持更新、取消与删除。更新失败保留旧包，删除不影响生字本；不自动下载全库。需 HTTPS 或电脑 localhost，普通 LAN HTTP 明确禁用，不通过浏览器安全设置绕过。实现及验收边界见 [离线字单](Web离线字单.md)。

## 顺序与交付边界

建议 **F1 字单管理 → F2 分享 → F3 打印 → F4 基础信息**。F4 来源核验可提前开展，不可用时不阻塞其他功能；F5 已按原型范围实施，iPad／Apple Pencil 输入已由用户确认，新增连续流程与 iPhone 手感仍待专项确认；F6 已按有限离线范围实现，主屏幕安装不纳入。

每项先落实交互与状态，再实现、验证、更新文档并提交，保持单项可审查。数据迁移、导入、链接参数与取消竞争需有效回归；打印看实际预览／PDF，练习做设备输入验证；不重复全部已有手机验收，只验证新增行为和受影响路径。

第一批完成边界：原有查字／播放稳定，F1—F3 可用，F4 有可信来源的字段可用，其他字段明确延期；主界面保持精简。交付时逐项列出完成与延期内容。用户已授权按计划逐步实施；进度以各项记录为准，不把规划当作已实现。

## 后延与保留待办

- 上线、托管平台、域名、缓存策略与回退：功能阶段后再推进，不再作为当前先行任务。届时仍需干净检出完整构建、产物检查和发布授权；既有未提交旧版资源不能直接纳入发布。
- 字库补齐、GF 0023 批量提取、全字库审核：按 [原计划 TODO](Web重构计划.md) 暂缓。棻、濛、皙、脩的名称／笔数冲突单独核验，可与 F4 协调，不扩为全库补齐。
- 核心缺陷、必要兼容性及可访问性随每项功能修复，不等上线再处理；不以全浏览器全设备穷举阻塞功能阶段。
- 真实音画偏差、手机响应分布仍未量化，不用手动验收或桌面 DOM 采样替代。
- 账号、教材／班级体系、AI 教练、拍照识别和原生 App 不进入本阶段；长期选择池见 [K12 产品探索](K12产品设计与Web重构规划.md)。
