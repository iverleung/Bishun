# Web 下一阶段工作计划

日期：2026-11-08。状态：规划，尚未授权实施或部署。

## 当前基线

新版已作为本地默认首页，核心查询、播放、逐笔定位、录音、历史、收藏和专注书写已实现；用户已确认 UI、录音试听和本轮手机验收没有问题。Chrome 核心流程、模拟网络故障及桌面 DOM 响应已有记录，具体证据见 [稳定性验证](Web稳定性验证.md) 和 [手机验收](Web浏览器与真机验收.md)。这些结果不等于所有浏览器、设备及物理音画时序均已量化验收。

下一阶段以“发布现有稳定能力，再做小步增强”为目标，保持现有精简界面。字库补齐与 GF 0023 批量提取已暂缓，不作为发布前提。原始重构范围与待办见 [Web 重构计划](Web重构计划.md)。

## 优先级与工作项

| 顺序 | 工作项 | 具体产出与完成标准 |
|---|---|---|
| P0-1 | 收拢验收和发布边界 | 更新当前状态，区分通过、未测和暂缓项；明确已知缺字、4 个名称／笔数冲突、离线限制及旧版边界；不再重复已通过的全量验收，修复后只回归相关流程 |
| P0-2 | 固化可复现的发布产物 | 在干净检出中用 `npm ci`、测试、构建生成完整 `dist/`；复用现有资源／录音检查，补足三入口引用、资源哈希和来源许可的统一产物检查；记录提交、资源版本及产物摘要。排查当前构建是否依赖未提交的旧版资源，保留用户本地改动，不能直接纳入发布 |
| P0-3 | 准备静态部署与回退方案 | 确定目标托管平台、域名及站点根路径；按平台提供配置和操作文档。HTML 与清单允许及时更新；带哈希资源可长缓存，固定版本字形／录音仅在内容不可变时长缓存；JSON／MP3 缺失返回真实 404，不回退 HTML；验证 HTTPS、MIME 类型及可用的传输压缩。保留上一份完整构建，定义整包切换和回退步骤 |
| P0-4 | 首次发布与线上冒烟 | 方案和产物可审查后，经用户授权部署；在真实域名验证首次查询、录音、切字、暂停、收藏刷新、三个入口和资源 404；确认无公共字库 CDN 请求、新旧版本缓存切换正常，并验证回退流程。发布后记录结果 |
| P1-1 | 解决已知内容冲突 | 专项核验棻、濛、皙、脩的字形笔数与名称序列，按规范逐字修正或明确保留降级；增加能检出旧问题的样本回归。不得用删除校验或强行对齐索引消除冲突 |
| P1-2 | 补齐关键兼容性检查 | 发布前优先做 Firefox／Edge 的查询、播放、取消、录音失败降级和存储冒烟；Android Chrome 有设备时补做。不重复要求已确认的 iPhone／iPad 手动验收；发现缺陷再定位和回归。未测环境如实记录，不无限扩大设备矩阵 |
| P1-3 | 基础可访问性收尾 | 检查输入、切字、逐笔、设置、字单和全屏退出的键盘路径、焦点、控件名称与状态播报；尊重减少动态效果偏好。发现实际障碍后定点修复，保持已确认的布局与信息密度 |

建议执行顺序：先完成 P0-1／P0-2；目标环境确定后完成 P0-3。P1 的内容冲突、关键兼容性和可访问性检查可在部署准备期间穿插，影响核心操作的缺陷需在 P0-4 前修复。没有目标环境时先交付可部署产物和通用配置要求，不假定某个平台，也不提前部署。

## 稳定发布后的功能候选

以下为候选，不自动进入实施范围；先选一项，再写交互和验收标准。新能力优先放入设置或分享动作，避免常态主界面增加按钮。

| 候选 | 用户价值 | 范围与依赖 |
|---|---|---|
| 分享当前字／字单 | 家长、老师直接发送需要看的内容 | 链接恢复查询但不自动播放；校验长度与字符；接收端仍按实际字库提示缺字，不共享本地收藏 |
| 打印练习纸 | 将查字自然延伸到纸上练习 | 先提供米字格、范字和空白格；验证 A4 打印与 PDF 导出布局，暂不叠加拼音释义或教材体系 |
| 安装到主屏幕及有限离线 | 手机更容易再次打开，减少重复加载 | 明确安装与离线是两件事；先定义应用壳、最近字和录音的缓存范围、更新与清理机制，再考虑 Service Worker；不默认下载全部字库 |
| 拼音、部首等基础信息 | 减少切换其他工具查资料 | 先确认数据许可与多音字呈现规则；按需展开，避免挤占画布。释义和词语另行确定来源 |

建议先评估“分享当前字／字单”，它直接复用已有查询与字单能力，数据和交互增量较小；打印次之。安装／离线涉及缓存更新和存储管理，单独设计，不并入首次发布。

## 暂缓与完成边界

- 字库全覆盖、GF 0023 图形批量提取、全字库人工审核：保留 [既有 TODO](Web重构计划.md#91-todo字库补齐与-gf-0023-数据提取暂缓)，以后单独排期。
- 全量离线包、账号同步、教材／班级体系、AI 评测和原生 App：不进入本阶段。
- 真实音画偏差、手机响应分布和网络切换的量化实验：仍属未完成验证；有同步缺陷或明确性能目标时安排专项测量，不把已有 DOM 采样当作物理媒体时序证据。
- 本阶段首个里程碑为“完整可复现产物、明确部署与回退方案、关键缺陷已处理”；实际发布需要用户授权。后续功能须单独确定范围。
