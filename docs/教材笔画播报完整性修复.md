笔画细分类参考此前已核验的 GF 2001—2001 第 9—10 物理页折笔表，仍使用项目已有的常用 UI 名称“卧钩”。原页五类数字代码用于顺序交叉检查，不用代码 5 自动决定具体折笔名称。

[核验记录](../resources/textbooks/textbook-stroke-review.json) 包含规范及命名参考 SHA-256、12 册内容版本、原字典候选、零起索引、确认名称、分类参考和核对图位置。只按字和索引修正；没有全局选择候选第一项或按相同部件自动替换。

## 自动检查与防回归

浏览器只载入[精简修正表](../resources/textbooks/textbook-stroke-corrections.json)，不下载核验页码等证据元数据。该 v3 块 gzip 为约 109.34 kB，较此次修复前增加约 3.11 kB；不是初次画面响应时间的量化结论。

```bash
npm run audio:strokes:check          # 严格检查，缺口会失败
npm run --silent audio:strokes:coverage
npm run strokes:prepare             # 审核源记录后显式生成精简修正表
```

`predev`／`prebuild` 自动检查：教材版本、字形 SHA-256、原字典候选与笔数、核验记录和精简表的一致性、教材逐笔名称／录音覆盖。普通构建不自动编造或刷新修正；资源或原候选变化必须先核验。现有音频检查继续校验所有实际录音文件。

新增隔离测试在临时副本中故意移除横钩录音、篡改原候选，均确认检查返回失败，不修改项目真实数据。
