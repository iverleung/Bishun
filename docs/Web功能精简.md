## 第二批：统一操作与按需展开（已实现）

- 取消快速看／听讲解／跟着写节奏选择，统一逐笔播放；声音和连续播放默认开启。保留上一笔／下一笔手动控制。声音需要用户点击播放后解锁，不自动播放。
- 播放设置按用户最新反馈默认展开，仍可手动折叠，只提供声音、连续播放和慢／正常／快三档速度。移除独立“整组从头播放”；连续播放从当前字到末尾，完成后主按钮重播从首字开始，显式“重播这个字”仍从当前字开始。
- 移除格线／轮廓设置和专注模式的入口、状态、全屏调用及样式。示范固定米字格和轮廓，直接使用已有默认居中画布。
- 屏幕练习从菜单移到画布下方，保留描红／背临、提示、重写与连续练习；进入后隐藏入口，返回示范后恢复。没有新增评分或学习记录。
- 收藏合并为一个入口：单字直接保存，多字才打开范围选择；取消不保存，已收藏范围不能重复保存。个人清单、名称及原去重语义不变。
- 生字本日常只展示打开清单和“管理”；编辑、排序、删除、导入／导出只在管理状态出现，空清单也能进入管理并导入。
- 分享保留系统分享、复制及手动复制，删除二维码界面、生成代码、原专项测试和两项专用依赖。已有内容链接不变。
- 打印默认直接打印整组，范围、格线、尺寸、行数和全局拼音开关收进“打印设置”。打印分页和许可附页保留。

旧偏好只迁移声音、连续播放及速度，旧速度 1／5 收敛到 2／4，分别对应慢／快；旧节奏及显示开关不再生效。新用户与恢复默认均开启声音、连续播放；已保存的显式开关选择继续保留，不清除历史或收藏。

修正两处折叠／入口调整暴露的焦点边界：菜单关闭后立即进入练习时，延迟 close 事件不再抢回菜单焦点；Tab 焦点列表排除关闭 details 中的设置及隐藏管理项。进入、下一字和重写继续聚焦练习面板，不自动打开原生模式选择器。
