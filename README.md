# 汉字笔顺工具（Bishun）

面向小朋友的汉字笔顺动画 Web 工具，支持多字顺序播放和笔画名称播报。项目使用 Vite、原生 JavaScript ES Modules 和 CSS，目前没有 UI 框架或动态后端。

## 访问入口

- `/`：新版默认首页（本地候选版，尚未部署）。
- `/preview/index.html`：原预览地址，自动转到新版，保留查询参数与片段。
- `/print/index.html`：独立练习纸预览，由新版打印入口携带汉字打开。
- `/legacy/index.html`：仅保留历史地址兼容，新版不再提供旧版导航入口。

候选版范围、入口验证和发布边界见 [首页切换记录](docs/Web首页切换候选版.md)。

## 开发与构建

依赖范围见 [package.json](package.json)，锁定版本见 [package-lock.json](package-lock.json)：HanziWriter ^3.7.3、cnchar ^3.2.6、cnchar-order ^3.2.6、cnchar-radical 3.2.6，以及开发依赖 Vite ^6.4.1。

```bash
npm ci
npm run dev
```

生产构建与本地预览：

```bash
npm run build
npm run preview
```

`predev`／`prebuild` 会从锁定的 `hanzi-writer-data@2.0.1` 开发依赖生成全量候选字形，需安装开发依赖后启动或构建。构建输出为 `dist/`，可部署到静态托管服务。`public/` 中的字形资源会复制到构建输出。构建脚本先清理生成目录 `dist/`，对暂时性目录占用最多重试 3 次，失败会中止构建。预览命令需要先构建；未构建的源代码依赖 Vite 解析 npm 导入，不能直接用普通静态文件服务器运行。目前根目录没有 `deploy.sh`。

## 当前功能

运行 `npm run dev` 后直接打开终端显示的地址 `/`（默认 `http://localhost:5173/`）；生产构建同样以 `/` 为新版入口。原预览链接继续可用，旧版保留为独立页面。W4 资源故障检查、偏好与字单能力见 [稳定性验证记录](docs/Web稳定性验证.md)。

新版保持已确认的精简界面：输入前突出输入框，查询后突出居中的大字画布，两侧候选在页边渐隐。支持最多 20 个 Unicode 汉字，保留词序与重复字；历史最新在左，支持复查与清空。

已接入本站 9,574 字候选字库、HanziWriter 真实轨迹动画和 26 份预生成录音。默认“快速看”静音；“听讲解”启用录音；“跟着写”每笔暂停。主页面保留播放、上一笔／下一笔和前后字；按编号定位与重播本笔入口已移除。单字／整组、速度、格线和轮廓等操作位于右上角菜单。暂停保留完成笔，中断笔继续时从笔首重播；切字、新查询、清空和后台暂停共用取消规则。录音失败时提示并静音继续，字形失败可重试或切字。

大字格左滑切下一字、右滑切上一字，重复字按原顺序切换，到首尾不循环；纵向滚动和双指缩放保持原生能力。练习模式不响应切字手势，避免将手写笔画误判为导航。右上角菜单以侧边抽屉打开，生字本展开不占主页面高度；选清单、进入练习／打印／全屏会收起抽屉，设置调整保持打开。打开菜单暂停当前演示或练习，关闭不自动继续；支持关闭按钮、遮罩及 Esc。选清单后聚焦播放控制，避免弹出输入键盘。触控使用独立 Touch Events 路径，横向意图明确后才阻止浏览器默认手势，鼠标／笔使用 Pointer Events；同宽度的窗口高度变化不再清除滑动。iPhone 用户截图确认专注布局已生效，Safari 栏仍在，因此入口统一改名“专注模式”；本次触控兼容修正及真机待确认范围见 [记录](docs/Web触控兼容修正.md)。

右上角菜单还提供专注模式与恢复默认设置。专注模式突出当前画布，不会自动进入屏幕练习。浏览器支持时尝试原生全屏，否则保留专注布局；退出按钮与 Esc 可返回。节奏、速度、语音、整组、格线与轮廓偏好保存在本机，刷新后保留，但不自动开始播放；恢复默认设置不清空查询历史。

支持在右上角菜单收藏当前字或这组查询。菜单内折叠的“我的生字本”可复查、管理和备份清单：支持命名、编辑、上移／下移及删除，最多 30 条，每条最多 20 字，保留字序与重复字。管理控件按需展开，空生字本也可导入备份。JSON 导入先预览可导入、重复、无效与超额条目，确认后仅追加有效内容，不覆盖旧清单或静默淘汰；导出仅含清单与名称。备份不超过 100 KB、500 项，名称最多 40 字。旧收藏读取兼容，首次修改写入独立 v2 存储，旧 v1 数据保持原样；清空历史和恢复默认不删除收藏。存储失败提示仅本次打开有效。

右上角菜单中的“分享”可选择当前字或当前组，生成仅包含汉字的链接（`#q=`），支持系统分享和复制／手动复制兜底。接收方恢复查询，不自动播放或收藏；最多 20 字，保留顺序与重复字，非法链接明确提示。链接不携带字单名称、历史和偏好；手动提交其他查询会清除旧分享参数，避免刷新恢复到旧内容。局域网开发地址只有可访问该地址的设备才能打开。

“打印练习纸”进入独立 A4 纵向预览，支持当前字／整组、米字格／田字格、三档格子大小和每字 1—3 行；每字包含范字、两格浅色描红和空白练习区。浏览器打印界面可在支持的设备另存 PDF；打印隐藏操作控件，附完整字形许可页。缺字或加载失败需重试或明确移除后打印；许可文件加载失败阻止打印。返回查字恢复原组，不自动播放。

大字格上方居中显示 cnchar 3.2.6 字典读音候选及当前字形笔数，普通查看时下方不重复显示总笔数，逐笔播放时下方显示进度。多音字全部列出，不按上下文擅选读音；缺失显示“暂缺”，不回显原汉字冒充拼音。查询／切字期间清除旧信息；基础信息本地计算，不增加远程字典请求；多音候选并列显示，窄屏可换行。部首信息暂时隐藏，页面不加载部首字典，待按大陆归部规范核验数据后再恢复。整字发音尚未加入，字典信息不代表全库教学审核；两个字典包共用随站点提供的原始 cnchar MIT 许可。

新增“屏幕练习”原型，入口位于右上角菜单。进入后放大当前画布，支持描写／独立写、提示下一笔、重写和返回示范；匹配当前字的笔顺与大致轨迹，写完当前字后可点“下一个字”，从进入时的当前字练到查询末尾，重复字逐个保留。结束后显示本次完成字数，可再练一遍；重写同一位置不重复累计，缺字／加载失败可重试或明确跳过，跳过不算完成。不评分、不标记掌握、不保存或上传手写轨迹。提示不计入完成，不在多次出错后强行放行。切字、新查询、清空或返回示范结束当前练习；后台／输入取消／画布尺寸变化暂停，保留已完成笔画，主动继续后从下一笔重写。详见 [练习原型](docs/Web屏幕练习原型.md)，用户已确认 iPad 与 Apple Pencil 输入正常；新增连续练习流程及 iPhone 手感仍需专项确认。

新版运行时只请求同源字形与录音，不依赖浏览器语音合成或公共数据 CDN。资源包存在缺字，名称未知显示“暂缺”，26 条录音已由用户确认试听通过，见 [试听清单与生成命令](docs/笔画录音试听清单.md)。当前断网复用仅覆盖同页已加载的字形和录音，不包含离线刷新或冷启动。开发验证、行为约定与待验收项见 [W3 播放重构记录](docs/Web播放重构.md)；原型阶段记录见 [W1 交付记录](docs/Web交互原型.md)。

## 测试与检查

```bash
npm test                # v3 样本、名称、资源、播放、音频及历史回归
node test/run.js v3      # 只运行 v3 字符样本
npm run test:preview    # 新版播放、音频与历史回归
```

测试读取 `test/data/` 中的字形 fixture。该目录在 `.gitignore` 中，但部分 fixture 已被 Git 跟踪；运行前需确认测试数据是否齐全。`test/download_data.js` 是需要网络的下载辅助脚本。

回归入口仅运行 v3；任一字不符合预期、fixture 缺失或笔画数量不一致都会返回非零。测试所需的 48 份 fixture 已纳入版本管理。

**当前回归：** W2 已按规范图形和笔形表复核 W0 差异，分别修正 5 处旧预期和具体字的名称查询；48/48 字、233/233 笔回归通过。依据与边界见 [Web 资源与内容核验](docs/Web资源与内容核验.md)，历史结果见 [Web 现状基线](docs/Web现状基线.md)。这仍不代表全字库审核或全库准确率。

新版另外通过 63 项 Node 回归，覆盖播放取消／续播、音画结束等待、加载超时、录音失败与历史等；不代替真实浏览器媒体验证。

连续练习专项：`node test/browser-practice-sequence.mjs <CDP地址> <新版页面地址>`，覆盖重复字、完成反馈、重练、缺字重试／跳过与加载期间取消。

部首专项：`node test/browser-radical.mjs <CDP地址> <新版页面地址>`，确认主界面、菜单及无障碍标签不展示部首，且不请求部首字典模块。来源与边界见 [基础信息记录](docs/Web单字基础信息.md)。

没有配置 lint、TypeScript 或类型检查脚本。可运行基础语法检查：

```bash
node --check src/main.js
node --check src/engine/speech.js
node --check src/engine/recognition/v3.js
```

另提供需要 Node 22+ 和已授权 CDP 接口的实际浏览器坐标回归：`node test/browser-geometry.mjs <CDP地址> <新版页面地址>`，比较播放中动画与静态字形的位置，含旧缺陷反例。网络回归为 `node test/browser-network.mjs <CDP地址> <新版页面地址>`，验证模拟弱网、断网缓存与重试。两项浏览器测试共用隔离 CDP 会话辅助代码，不影响已有标签页。性能采样入口为 `node test/browser-performance.mjs <CDP地址> <新版页面地址>`；要求测试窗口真实保持前台。桌面 Chrome 每项 30 次的 DOM 响应采样已完成，见 [性能记录](docs/Web稳定性验证.md#第九批性能采样准备与构建完整性)；不代表实际画面呈现或音频时序通过。生字本专项检查为 `node test/browser-library.mjs <CDP地址> <新版页面地址>`，文件上传／下载检查要求 CDP 浏览器与脚本在同一主机。抽屉与滑动专项为 `node test/browser-drawer-swipe.mjs <CDP地址> <新版页面地址>`；先前 Headless 环境的触控回执阻塞已在用户提供的 9223 Chrome 中复测通过，`--native-touch` 同时检查原生短拖动与纵向滚动；记录见 [CDP 复测](docs/验收记录/drawer-swipe-cdp-9223-2026-11-08.json)，真机 Safari 滑动仍待专项确认。尚无完整的浏览器自动化覆盖或经过验证的浏览器版本支持矩阵。布局和媒体播放需要在实际浏览器与代表性移动设备上检查。Chrome/CDP 已完成部分真实浏览器检查；iPhone／iPad Safari 优先的步骤、实际结果与待验收范围见 [浏览器与真机验收](docs/Web浏览器与真机验收.md)。

## 汉字数据与内容

W2 新增 `/characters/2.0.1/` 自托管候选字库：9,574 字，原始约 32.2 MB，按字请求。对规范表 8,105 字实测覆盖 6,866 字，仍缺 1,239 字，不能宣称全覆盖。`src/data/character-store.js` 已实现同源加载、缓存、去重、超时与结构校验，已接入新版，旧首页仍使用原有入口。使用 `npm run resources:check` 核对生成资源；完整审计见 [资源与内容核验](docs/Web资源与内容核验.md)。


旧首页字形数据优先从 `public/hanzi-writer-data/` 加载，目前包含一批测试集常用字。未收录的字会依次尝试国内镜像和海外 CDN。新增字形时可在该目录加入兼容 HanziWriter 格式的 JSON，但还应校验路径、笔画数、顺序及名称对应关系。

动画路径由 HanziWriter 数据提供，笔画名称来自 cnchar；两者的对应关系需要核验。新版使用 v3 字典查询，保留的 v1／v2 几何算法不表示已支持用户手写识字。笔画分类参考 [STROKE_REFERENCE.md](STROKE_REFERENCE.md)，仓库也包含 GF0023-2020 规范 PDF；参考文档本身不等于全字库已完成规范审核。

### 旧版已知限制

- 输入当前采用 `/[^\u4e00-\u9fa5]/g` 过滤，不覆盖全部 Unicode 汉字。
- 暂停主要保存字位置，继续时可能从该字首笔重播，尚未实现可靠的笔画级恢复。
- v3 缺失或未核验的歧义名称显示“暂缺”；已有具体字修正，其余字典结果仍未完成全库教学审核。
- 数据源串行尝试且无显式超时；本站资源覆盖不完整，也未实现完整离线支持。
- 播放阶段会另行调用 `HanziWriter.loadCharacterData`，尚未统一复用预加载数据及自定义来源。
- 语音仍依赖浏览器合成，动画与语音的同步、播放取消及移动端交互需要重构。
- 目前没有屏幕手写练习、拍照查字、拼音释义、教材同步、账号或原生 App。
